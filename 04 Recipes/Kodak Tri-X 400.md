# Kodak Tri-X 400

A gritty, classic black-and-white look modelled on Kodak Tri-X 400 — the definitive street and documentary film. Built on Acros with heavy grain and high clarity for a tactile, contrasty monochrome rendering that holds up at very high ISO.

> [!info] Compatibility
> Recipe was built on the **X100V** and is **fully compatible with the X100VI** (same Acros-capable processor lineage). Apply the values as-is.

## Settings (X100VI)

| Parameter | Value |
|---|---|
| Film Simulation | Acros (try +R filter / Acros+R) |
| Dynamic Range | DR200 |
| Tone Curve — Highlight | 0 |
| Tone Curve — Shadow | +3 |
| High ISO NR | −4 |
| Sharpening | +1 |
| Clarity | +4 |
| Grain Effect | Strong, Large |
| Color Chrome Effect | Strong |
| Color Chrome FX Blue | Off |
| White Balance | Daylight, +9 Red / −9 Blue |
| ISO | 1600–12800 |
| Exposure Compensation | +1/3 to +1 (typical) |

### Tone tweaks by scene contrast

| Scene | Highlight | Shadow |
|---|---|---|
| Normal (default) | 0 | +3 |
| Low-contrast (flat/overcast) | −1 | +2 |
| High-contrast (harsh sun) | +1 | +4 |

## Personality

Punchy, grainy, and timeless. Shadow +3 deepens the blacks for that classic Tri-X bite, while Clarity +4 and Grain Strong/Large add coarse texture that flatters street and documentary work. The recipe is built to be shot dirty — at ISO 1600–12800 — so the grain and high-ISO texture become part of the aesthetic rather than a flaw. Push exposure slightly positive to keep mid-tones from going murky.

## Watch-points

- Intended for **high ISO (1600–12800)**; at base ISO the look can feel too clean for the aesthetic.
- Clarity +4 plus Shadow +3 is contrasty — use the low-contrast tone tweak (Highlight −1, Shadow +2) for flat overcast scenes to avoid blocked-up shadows.
- The extreme +9 Red / −9 Blue WB shift drives the Acros tonal separation; it has no color effect (it is a monochrome film sim) but changes how colors map to grey.
