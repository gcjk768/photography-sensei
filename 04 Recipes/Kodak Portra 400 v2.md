# Kodak Portra 400 v2

A warm, low-contrast portrait look modelled on Kodak Portra 400 — the classic flattering-skin negative film. Built on Classic Chrome with a wide dynamic range and soft rendering for forgiving golden-hour people shots.

## Settings (X100VI)

| Parameter | Value |
|---|---|
| Film Simulation | Classic Chrome |
| Grain Effect | Strong, Small |
| Color Chrome Effect | Strong |
| Color Chrome FX Blue | Off |
| White Balance | 5200K, +1 Red / −6 Blue |
| Dynamic Range | DR400 |
| Tone Curve — Highlight | 0 |
| Tone Curve — Shadow | −2 |
| Color | +2 |
| Sharpness | −2 |
| High ISO NR | −4 |
| Clarity | −2 |
| ISO | Auto, up to 6400 |
| Exposure Compensation | +1/3 to +1 (typical) |

## Personality

Warm, soft, and gentle on skin. The DR400 protects highlights in bright backlit golden-hour scenes, while Shadow −2 keeps the shadows airy rather than crushed. Sharpness −2 and Clarity −2 soften micro-contrast for a flattering, slightly creamy portrait rendering, and the warm 5200K + Red shift gives the amber, sun-kissed Portra tone. Push exposure a touch positive (+1/3 to +1) for that bright, low-contrast negative-film feel.

## Watch-points

- **Lift exposure deliberately.** Portra looks best slightly overexposed; at base exposure it can read flat and dark. Use +1/3 to +1 EV.
- DR400 forces a higher minimum ISO (typically ISO 640+ on the X100VI) — fine outdoors, watch it in dim interiors.
- The warm WB is tuned for golden hour; under midday or shade it can look too orange — dial the Red shift back toward 0.
