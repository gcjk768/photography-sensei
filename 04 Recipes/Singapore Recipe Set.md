# Singapore Recipe Set

Seven X100VI recipes tuned for Singapore's specific light: a near-vertical equatorial sun, frequent haze, sudden monsoon storms, lush greenery, and neon-soaked wet nights. Each section below is a complete, ready-to-dial recipe.

> [!tip] Two governing rules
> **(a) In harsh light, protect highlights** — raise Dynamic Range (DR200/DR400) and/or set D Range Priority so the midday sun and bright skies don't clip (JPEG-only means clipped highlights are gone for good).
> **(b) Match clarity to the air** — use *negative* clarity for clear, clean, dreamy light, and *positive* clarity to cut through hazy, flat, low-contrast days.

## 1. Equator Noon

*Governing idea: brutal vertical midday sun — protect highlights above all.*

| Parameter | Value |
|---|---|
| Film Simulation | Classic Chrome |
| Dynamic Range | DR400 |
| D Range Priority | Auto |
| Tone Curve — Highlight | −1 |
| Tone Curve — Shadow | +1 |
| Color | +1 |
| Clarity | +1 |
| White Balance | Auto, 0 Red / 0 Blue |
| Grain Effect | Off |
| Color Chrome Effect | Strong |

DR400 plus D Range Priority Auto fights the harsh tonal range of a near-vertical sun, holding skies and shirts off the clip point. Classic Chrome keeps saturation restrained so the scene doesn't go garish under hard light.

## OPPO Find N5 (phone) field notes

When J only has the phone, aim to get as close to the Fuji discipline as the hardware allows:

- **Shoot Pro mode + Hasselblad colour + RAW (DNG).** RAW preserves latitude the JPEG pipeline throws away and is essential for matching the Fuji look in edit.
- **Expose for the highlights.** As with the X100VI, protect bright skies and neon — recover shadows later from RAW.
- **Avoid the 8MP ultra-wide in dim light.** The small UW sensor falls apart at night; stick to the main camera in low light.
- **Skip auto night-mode for moody shots.** Night mode brightens and flattens, killing the mood — shoot manually and keep the darkness intentional.

### Lightroom Mobile "FujiCN-ish" preset (match the X100VI)

A starting preset to bend phone RAW toward the Classic Negative baseline:

- **Tone curve / blacks:** lift the blacks slightly (faded-film blacks — raise the bottom-left point of the curve).
- **Split toning / color grading:** **teal in the shadows, amber in the highlights** — the signature Classic Negative split.
- **Clarity / Texture:** pull clarity slightly negative for the soft, dreamy micro-contrast.
- **Saturation:** restrained — nudge greens down (HSL) so foliage doesn't go lurid, matching the Color +2 watch-point.
- **Grain:** add subtle grain (low amount, medium size) to mimic Grain Weak, Large.
- **White balance:** lean slightly warm to echo the warm-leaning Classic Negative looks.

Save as a preset and apply on import, then fine-tune per scene.
