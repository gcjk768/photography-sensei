# Kodachrome 64

A punchy, saturated slide-film look for bright daylight. Built on Classic Chrome with lifted color and positive clarity so blue skies and warm subjects "pop" the way Kodachrome 64 transparencies did.

## Settings (X100VI)

| Parameter | Value |
|---|---|
| Film Simulation | Classic Chrome |
| Grain Effect | Weak, Small |
| Color Chrome Effect | Strong |
| Color Chrome FX Blue | Off |
| White Balance | Daylight, +2 Red / −5 Blue |
| Dynamic Range | DR200 |
| Tone Curve — Highlight | 0 |
| Tone Curve — Shadow | +0.5 |
| Color | +2 |
| Sharpness | +1 |
| High ISO NR | −4 |
| Clarity | +3 |
| ISO | Auto, up to 6400 |
| Exposure Compensation | 0 to +2/3 (typical) |

## Personality

Bright, crisp, and saturated with a slightly warm, clean-shadow rendering. The DR200 plus warm Daylight shift holds blue skies while keeping skin tones healthy; Clarity +3 and Sharpness +1 give the image a defined, "ready-to-print" snap. This is a sunny-day, blue-sky travel look — best when the light is hard and you *want* the contrast and saturation rather than fighting it.

## Watch-points

- Designed for **bright daylight**; in flat overcast it can look cool and dull. Reduce the Blue shift or bump exposure if it goes muddy.
- Color +2 with Color Chrome Strong is intense — greens and reds can over-saturate; ease Color toward 0 for foliage-heavy frames.
- The +2 Red / −5 Blue shift is warming; verify skin tones don't go orange under tungsten or mixed light.
